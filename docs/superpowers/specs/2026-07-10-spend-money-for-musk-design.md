## 一、项目概述

一个纯 H5 移动端微信小游戏。玩家扮演马斯克，花掉他的实时身价。可购买从日常咖啡到荒诞离谱的各类商品，查看成就和称号，生成分享海报。

### 核心体验

- 打开即玩，无注册登录
- 超大金额花钱的爽感 + 搞笑荒诞的品类
- 成就和称号驱动的炫耀分享

---

## 二、技术选型

| 项 | 选择 |
|----|------|
| 架构 | 单 HTML 入口 + ES Modules，hash 路由 SPA |
| 构建 | 零构建工具，原生 ES Modules |
| 存储 | localStorage |
| 目标平台 | iOS 12+ / Android 8+ 微信内置浏览器 |
| 货币默认 | 根据 `navigator.language` 自动选 ¥/$，可手动切换 |

## 五、数据模型

### localStorage 存储结构

```js
{
  nickname: "花钱小能手",        // 用户昵称（默认随机生成）
  balance: 350000000000,         // 剩余资金（美元，内部始终用美元存储）
  totalSpent: 0,                  // 累计已花金额（美元）
  purchasedItems: [               // 购买记录
    { id, name, category, price, qty, time }
  ],
  cart: [                         // 当前购物车
    { id, name, price, qty }
  ],
  unlockedAchievements: [],       // 已解锁成就 id 列表
  unlockedTitles: [],             // 已解锁称号 id 列表

  cachedNetWorth: 350000000000,   // 上次缓存的身价
  cachedNetWorthTime: null,       // 上次缓存时间戳
  currency: "auto"                // 货币偏好：auto | cny | usd
}
```

## 七、页面详情

### 7.1 商店主页 (#shop)

布局自上而下：

1. **身价展示区**：实时身价数字（大字体），旁边显示当前佩戴称号
2. **花钱进度条**：渐变进度条，显示 `已花 ¥xxx / 剩余 ¥xxx`，百分比
3. **昵称行**：`👤 昵称 · 称号`，点击昵称可编辑（弹窗输入，限 10 字）
4. **搜索框**：实时过滤商品名和描述
5. **分类 Tab**：横向滑动，12 个分类，选中高亮
6. **商品网格**：2 列网格，每张卡片显示 emoji + 名称 + 价格 + "+"按钮
7. **底部导航**：商店 / 购物车（角标）/ 成就

#### 交互

- 点击"+"：抛物线飞入动画，购物车角标 +1，进度条不动（需结算才扣款）
- 商品卡片长按：弹出详情弹窗
- 搜索：输入即过滤，debounce 150ms
- 切换分类：商品列表横向滑动过渡

### 7.2 购物车 (#cart)

布局：

1. 商品清单：每行显示 emoji + 名称 + 单价 + 数量调整（- / 数字 / +）+ 小计
2. 减到 0 自动移除
3. 底部固定栏：合计件数 + 总金额 + "清空购物车" + "一键结算"
4. 空购物车状态："购物车空空如也，去逛逛吧～" + 跳转商店按钮

#### 结算逻辑

- 校验余额是否充足（余额不足 → toast 提示"马斯克的钱也不够花了…"）
- 扣减余额，累加 totalSpent，清空购物车
- 弹出结算动画（canvas 粒子撒花，持续 2 秒）
- 检查是否触发新成就/称号，有则依次弹出 toast

### 7.3 成就页 (#achievements)

布局：

1. **称号墙**：当前佩戴称号醒目展示，已解锁称号列表，可点击切换佩戴
2. **花费统计**：累计花费大头数字 + 剩余金额
3. **成就徽章墙**：所有成就网格展示，已解锁亮色，未解锁灰色带 🔒
4. **品类消费分布**：横向条形图，各类消费金额和占比
5. **跳转分享按钮** → 切换到 #share

#### 称号切换

点击已解锁称号 → 设为当前佩戴 → 全局刷新称号显示

### 7.4 分享页 (#share)

布局：

1. 昵称 + 当前称号
2. 累计花费大头数字 + 剩余金额
3. 已解锁成就徽章精选（前 5 个）
4. 品类消费 Top3 条形图
5. "生成分享海报"按钮（调用 share-card-generator skill）
6. "复制链接"按钮

#### 分享海报

由 share-card-generator 生成精美海报图片，包含：
- 昵称 + 称号
- 累计花费金额
- 精选成就徽章（3-5 个）
- 品类消费 Top3
- 引导文案："你也来替马斯克花钱吧！"

## 十、马斯克身价 API

### 主方案

使用 Yahoo Finance 非官方接口获取 TSLA 实时股价：

```
GET https://query1.finance.yahoo.com/v8/finance/chart/TSLA?interval=1d&range=1d
```

推算公式：`身价 ≈ TSLA股价 × 马斯克持股数(~4.11亿股) × 0.7(折算系数含SpaceX等)`。

### 降级策略

1. 请求成功 → 更新身价和缓存
2. 请求失败/超时 5 秒 → 使用 localStorage 缓存值
3. 无缓存 → 使用内置默认值 $3500 亿

### 刷新策略

- 页面加载时请求一次
- 之后每 5 分钟静默刷新
- 身价变化用 requestAnimationFrame 平滑动画过渡，不突兀跳变

## 十一、动画清单

| 场景 | 动画 | 实现 |
|------|------|------|
| 进度条增长 | 宽度 transition | CSS transition 0.6s cubic-bezier |
| 金额数字跳动 | 逐帧递增到目标值 | requestAnimationFrame |
| 加入购物车 | 抛物线飞入 + 弹跳 | CSS transform + transition |
| 结算撒花 | 彩色粒子散落 | Canvas 粒子系统，2 秒 |
| 成就解锁 | 全屏 toast + 徽章弹入 | CSS keyframes |
| 页面切换 | 淡入淡出 | CSS opacity transition |
| 分类切换 | 商品列表横向滑动 | CSS transform translateX |

## 十二、货币切换

- **内部存储**：所有金额以美元存储
- **自动检测**：`navigator.language === 'zh-CN'` → 人民币，其余 → 美元
- **手动切换**：设置按钮可切换（存入 localStorage.currency，覆盖自动检测）
- **展示转换**：人民币模式 × 7.2 汇率，格式化带符号（¥ / $）和千分位
- **影响范围**：身价显示、商品价格、购物车、结算、成就统计、分享页全部跟随

## 十三、兼容性 & 性能目标

- 目标浏览器：iOS 12+ Safari WKWebView / Android 8+ Chrome/微信 X5
- ES Modules：微信内置浏览器均支持
- 无外部图片依赖：全部使用 emoji，首次加载 < 300KB
- 商品列表超过 50 条启用虚拟滚动（只渲染可视区域 + 上下各 10 条缓冲）
- 搜索 debounce 150ms
- CSS Variables 做主题色，方便换肤

## 十四、不包含的范围

- 无后端服务，纯前端
- 无真实支付/微信支付对接
- 无用户注册/登录
- 无排行榜（后续迭代可加）
- 不接入真实汇率 API，使用固定汇率
